# Portfolio Personal Semántico y Accesible

**Estudiante:** Randy David Bermudez Garcia
**Asignatura:** Programación Web
**Universidad:** UCLV

## Descripción
Este proyecto es la entrega del Laboratorio 1 del Tema 1. Consiste en un portfolio personal construido con HTML5 puro (sin CSS ni JavaScript), enfocado en el marcado semántico, la accesibilidad WCAG AA y el SEO on-page.

## Estructura
- `index.html`: Página principal (Sobre mí y habilidades).
- `proyectos.html`: Listado de proyectos con multimedia.
- `cv.html`: Currículum vitae detallado.
- `contacto.html`: Formulario de contacto validado.
- `assets/`: Carpeta que contiene imágenes, documentos y multimedia.

## Herramientas de validación utilizadas
- [W3C Validator](https://validator.w3.org/) - Para validar el código HTML.
- [WAVE](https://wave.webaim.org/) - Para auditar la accesibilidad.
- [Lighthouse](https://developer.chrome.com/docs/lighthouse/) - Para medir SEO y rendimiento.

## Notas de entrega
Las capturas de pantalla de la validación (W3C y Lighthouse) se encuentran en la carpeta `assets/docs/`.
